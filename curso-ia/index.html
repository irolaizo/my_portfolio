2 · definición

¿Qué es la inteligencia artificial?

Un campo de la informática que busca crear sistemas capaces de imitar el comportamiento humano inteligente: aprender, razonar, percibir y tomar decisiones de forma autónoma para lograr objetivos concretos.

Juntar esas cuatro capacidades en una sola solución es muy difícil. Por eso la IA es hoy un tema tan relevante: permite combinarlas para resolver problemas complejos que antes no tenían solución.

3 · historia

70 años de IA: teoría, invierno, renacimiento y explosión

La teoría nació en los años 50, pero la IA solo despegó cuando hubo datos y potencia de cálculo para aplicarla.

  1. 1950s

    El nacimiento

    Alan Turing propone el Test de Turing. En 1956, el taller de Dartmouth, liderado por John McCarthy, acuña el término "Inteligencia Artificial". Nacen las bases teóricas que todavía usamos.

  2. 1968

    La ciencia ficción marca el camino

    2001: Una odisea del espacio. La ficción avanza en paralelo a la técnica real y guía la imaginación sobre los siguientes pasos posibles.

  3. 1980s

    El invierno de la IA

    Las expectativas superan a los resultados reales y se congela la inversión de universidades y empresas. Solo algunos laboratorios mantienen el ritmo.

  4. 1997

    El renacimiento: Deep Blue

    El ordenador de IBM vence al campeón mundial de ajedrez Garry Kasparov, que protestó porque la máquina se había preparado con sus partidas y con una enorme base de datos.

  5. 2010s

    La explosión del Big Data

    Big Data, GPU potentes y técnicas maduras. Las empresas extraen valor de sus datos con Machine Learning y resuelven problemas antes imposibles: la "edad dorada".

  6. Hoy

    IA generativa y agentes

    ChatGPT, Gemini, Midjourney… y los agentes como puente hacia una IA más general.

¿Por qué el ajedrez?

Los juegos tienen reglas estrictas, así que son un entorno ideal para medir y comparar la inteligencia humana y la artificial. Su pega: están muy aislados de la realidad.

¿Por qué fue clave el Big Data?

Primero se acumularon y limpiaron enormes conjuntos de datos; después, el Machine Learning permitió extraer su conocimiento. Esa revolución técnica pasó luego al negocio: conocer al cliente, recomendar productos…

4 · conceptos base

Las capas de la IA

Hoy, hablar de IA es casi siempre hablar de Machine Learning: alrededor del 99 % de las soluciones que llamamos IA aprenden de datos.

El campo de estudio que da a los ordenadores la capacidad de aprender sin ser programados explícitamente.Arthur Samuel, sobre el Machine Learning

Toda solución de ML combina tres cosas: un conjunto de datos, una técnica capaz de encontrar patrones en ellos y un objetivo, la pregunta que queremos responder. Nosotros elegimos la técnica, pero las reglas las encuentra ella sola: esa es la "magia".

Los 3 tipos de aprendizaje

Supervisado

Conocemos la respuesta

Hay una variable objetivo y medimos si nos acercamos a ella.

Ej.: detectar spam con correos ya etiquetados.

No supervisado

No hay respuesta

El sistema agrupa los datos por su parecido.

Ej.: agrupar clientes por hábitos de compra.

Por refuerzo

Prueba y error

Recompensas y castigos guían el aprendizaje hacia una meta.

Ej.: aprender a jugar sumando puntos al ganar.

6 · proyectos

Los 4 ingredientes de un proyecto de IA

Ninguna solución sale de la nada: necesita datos, un modelo, una salida medible y computación. Y están acoplados: elegir uno condiciona a los demás.

Por qué empezar por la salida

  1. Valida el modelo: sin una métrica clara no sabes si el modelo aprende bien.
  2. Guía las decisiones: añadir datos o más potencia depende de si te acercas al objetivo.
  3. Ahorra recursos: evita gastar tiempo y computación en modelos que no resuelven el problema real.

7 · evolución

Hoy estamos en el puente: los agentes

Convivimos con dos tipos de IA, estamos cruzando un puente y en el horizonte aparecen la IA general y la superinteligencia.

IA generativa

Le pides "escríbeme un correo de queja al proveedor" y lo redacta perfecto, pero eres tú quien lo copia, lo pega en el correo y lo envía.

Agente

Le dices "cancela mi reunión de las 17:00 y avisa al equipo". Se conecta a tu calendario, borra el evento, redacta la disculpa y la envía él solo.

A diferencia de un chatbot, que solo responde, un agente planifica y ejecuta una serie de pasos para lograr un objetivo complejo.

1 · introducción

Lo justo de Python para trabajar con datos

Una sesión práctica: no se aprende Python entero, que es enorme y sirve hasta para webs o drivers de hardware, sino solo lo imprescindible para el análisis de datos y la IA.

Objetivos de aprendizaje

  1. Entender los fundamentos de Python que se usan en proyectos de datos e IA.
  2. Manejar los tipos de datos: enteros, decimales, valores lógicos y texto.

la idea claveLa máquina no entiende el mundo como nosotros: hay que "empaquetarle" la información en contenedores lógicos. Saber si un dato es un entero, un decimal, un valor lógico o un texto es el primer paso para traducir la realidad a su idioma.

Inferencia de tipos

int + float = float. El decimal "cubre" a los enteros y no se pierde información: 3 + 3.0 → 6.0.

6 · estructuras (I)

Listas: muchos datos bajo un nombre

Una lista es una secuencia ordenada entre corchetes [ ]. Es como una lista de la compra en una pizarra magnética: se puede añadir, quitar y cambiar (es mutable).

my_list = [1, 2, 3, 4]        # con datos
empty = []                    # vacía, para rellenar después
user = ["Carlos", 35, True]   # se pueden mezclar tipos
len(my_list)                  # 4

La regla de oro: Python empieza a contar en 0. También se puede contar desde el final con negativos, empezando en -1. Y con lista[inicio:fin:paso] se extrae un trozo (slicing); el límite final no se incluye.

7 · estructuras (II)

Tuplas y diccionarios

Las tuplas son listas blindadas que no se pueden cambiar; los diccionarios organizan los datos por etiquetas en vez de por posiciones.

Tuplas: inmutables

coordinates = (40.4, -3.7)   # paréntesis
coordinates[0]               # 40.4 ← se leen como una lista
coordinates[0] = 41.0        # ❌ TypeError: 'tuple' object does not support item assignment
my_data = 1, 2, 3            # sin paréntesis: Python crea una tupla sola (packing)
a, b, c = 1, 2, 3            # tres variables independientes

Es como un ticket impreso: definitivo. En IA sirven para datos que no deben cambiar nunca, como coordenadas fijas o los hiperparámetros de un algoritmo.

Diccionarios: clave → valor

d = {"A": 1, "B": 2}   # llaves y pares clave: valor
d["A"]                 # 1
d.keys()               # dict_keys(['A', 'B'])
d.values()             # dict_values([1, 2])
d.items()              # dict_items([('A', 1), ('B', 2)])
"C" in d               # False
d["C"]                 # ❌ KeyError: la clave no existe
d.get("C", 23)         # 23 ← valor por defecto, sin error
d.get("C")             # None ← "vacío", sin romper el programa
Nivel básico · peligro

dic["key5"]: si falta la clave, KeyError y el programa se para.

Nivel intermedio · seguro

if "key5" in dic: y después extraer.

Nivel experto · óptimo

dic.get("key5", 0): una línea, limpia y sin errores.

8 · control de flujo

Decisiones y bucles

El código deja de ser estático: los condicionales deciden qué camino seguir y los bucles repiten tareas sobre muchos datos.

x = 5
if x > 10:
    print("Mayor que 10")    # 1.º se comprueba esto
elif x > 3:
    print("Entre 4 y 10")    # 2.º si lo anterior es False
else:
    print("3 o menos")       # 3.º si todo lo anterior es False

Python entra solo en la primera rama que sea True. Por eso hay que ordenar de lo más concreto a lo más general. Y nunca olvidar los dos puntos ni la sangría.

while: mientras se cumpla… y el peligro del bucle infinito

El curso lo explica con la analogía del grifo abierto: mientras el grifo esté abierto (condición True), el agua corre. Si te vas sin cerrarlo, la casa se inunda.

checklist antes de ejecutar un while1) ¿Empieza con una condición True? 2) ¿Hace la tarea que quiero? 3) Crítico: ¿hay algo dentro que acabará volviendo la condición False? Si no, ¡no lo ejecutes!

for y range(): recorrer elemento a elemento

for animal in ["perro", "gato", "loro"]:
    print(animal)          # perro, gato, loro

for i in range(5):         # 0, 1, 2, 3, 4 (el 5 no se incluye)
    print(i)

range(2, 6)                # 2, 3, 4, 5
range(0, 10, 2)            # 0, 2, 4, 6, 8
whilefor
Se repite…Mientras se cumpla una condiciónUna vez por cada elemento
Variable de controlLa actualizas túLa gestiona Python
AnalogíaInflar un globo hasta llenarloPasar lista en clase
en IALos condicionales limpian datos; los bucles son el mecanismo del aprendizaje: al entrenar una red neuronal, un for con range() define las épocas, cuántas veces repasa el algoritmo todos los datos.

9 · reutilizar

Funciones y módulos: no reinventar la rueda

El curso lo explica pensando como un chef: una función es tu tarjeta de receta, escrita una vez y usada siempre; un módulo es una salsa ya hecha del supermercado.

def suma(x, y):                       # def + nombre + parámetros + dos puntos
    """Devuelve la suma de x e y."""   # docstring
    return x + y                      # entrega el resultado

suma(2, 3)        # 5 (por posición)
suma(x=2, y=3)    # 5 (por nombre)

El algoritmo completo

El ejemplo final del curso une todo: un módulo, una lista de diccionarios, una función, un bucle, extracción segura y una decisión.

# 1. MÓDULOS
import time

# 2. ESTRUCTURAS: un dataset como lista de diccionarios
sensor_dataset = [
    {"id": 1, "temperature": 22.5},
    {"id": 2, "temperature": 80.0},   # ¡anomalía!
    {"id": 3, "temperature": 21.0},
]

# 3. FUNCIONES
def process_data(data):
    print("Starting AI analysis...")
    for sensor in data:                              # 4. BUCLE
        current_temp = sensor.get("temperature", 0)  # 5. EXTRACCIÓN SEGURA
        if current_temp > 50.0:                      # 6. DECISIÓN
            print(f"ALERT: Sensor {sensor['id']} overheated ({current_temp}°C).")
        else:
            print(f"Sensor {sensor['id']} stable.")
        time.sleep(1)

process_data(sensor_dataset)
